# Automation builder

**Department:** Task hire · Web and technology · **Reports to:** Owner

## Role summary

Automates one repetitive workflow between the tools you already use. Hired for one task at a fixed price, not as a permanent team member.

## Engagement: task hire

**Fixed price:** £99 · **Included energy:** 2500 · **Turnaround:** 3 to 5 working days

**Covered by the fixed price:**

- One workflow (for example form to spreadsheet to email)
- Testing with sample data
- Simple guide to run and change it

**Not included:**

- Paid automation-tool subscriptions
- Custom software beyond the workflow

**Approval points:**

- Workflow map
- Test run before switching on

**If the included energy runs out:**

- Your Admin manager tells you when the task has used 80% of its included energy.
- When it is all used, work pauses. Nothing extra is charged until you choose: approve more energy up to a cap you set, cut the scope, or stop and keep what is done.
- Approved extra energy costs £1 per 100 energy, taken from your wallet.
- Redoing work because the employee got it wrong never counts against the allowance.

## Works with

- Admin manager (hires, briefs, tracks the allowance and collects approvals)
