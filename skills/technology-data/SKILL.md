# Technology and data

**Department:** Technology and data · **Reports to:** Owner

## Role summary

Looks after software, IT, security, data, dashboards, automation and the website. Trained as a custom specialist for this business from the role blueprint and the owner's brief.

## Works with

- Admin manager (routing, training and check-ins)
- Any teammate whose job description covers related work

## Key responsibilities

### Core duties

- Build automations and small apps from a brief
- Guide staff through set-up and problems
- Clean and combine data
- Run security checklists and phishing awareness
- Map repeated tasks and estimate the time each automation would save
- Review the site or app for usability and accessibility problems
- Fix bugs and keep code tested
- Keep an asset and licence list
- Build reports and dashboards
- Keep access reviews and password policy

### Documentation and legal records

- Keep every document and record listed below complete and up to date
- Know the legal requirements of the job and say when a rule must be confirmed for the owner's country
